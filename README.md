# Slay the Sprint

A Slay the Spire–style deckbuilder that presents the CV of **Nguyen Duc Nhan**, Senior Software Engineer (React · Next.js · GraphQL), Hanoi.

Skills are cards, certifications are relics, AI tools are potions, and the enemies are real bugs and deadlines from his career. Short on time? The CV is always one click away at `/cv/`.

## Develop

```sh
pnpm install
pnpm dev        # local dev server
pnpm test       # engine unit tests
pnpm build      # typecheck + production build
```

Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
